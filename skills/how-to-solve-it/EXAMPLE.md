# 实例演示

> **关键提醒**：下面的例子是数学的，但方法论是通用的。数学中的"数据/未知量/条件"等价于编程中的"现有代码/目标/需求"。请在每个阶段末尾的「编程迁移」中寻找映射关系。

---

## 问题

**已知长方体的长、宽、高，求其对角线长度。**

---

## 阶段一：理解问题

### 核心三问

1. **未知量是什么？** — 长方体对角线的长度。
2. **已知数据是什么？** — 长、宽、高。
3. **条件是什么？** — 对角线连接的是长方体的两个相对顶点。

### 追问

- 条件有可能满足吗？— 是，任何长方体都有对角线。
- 条件足以确定未知量吗？— 是，给定 a、b、c，对角线就确定了。
- 画图。引入记号。— 令对角线的长度为 x，长、宽、高分别为 a、b、c。

```
        ________
       /       /|
      /       / |
     /_______/  |
     |       |  |
     |       | /
     |_______|/

    x = 所求对角线
    a, b, c = 已知边长
```

### 编程迁移

| 数学 | 编程等价 |
|------|----------|
| 未知量 = x | 目标：要实现什么？输出什么？ |
| 已知数据 = a, b, c | 输入：现有 API、已有函数、外部依赖 |
| 条件 | 验收标准：期望行为、边界情况、性能要求 |
| 画图 | 画架构图、调用关系图、时序图 |
| 引入记号 | 命名变量/函数/模块。好的命名 = 好的理解 |

---

## 阶段二：制定方案

### 寻找思路

**问：你知道一道相关的问题吗？**

答：不知道专门关于长方体对角线的问题。

**问：看着未知量！试想一道具有相同或相似未知量的熟悉问题。**

答：未知量是一条线段的长度。我解过求线段长度的问题——比如直角三角形的边长。

**问：这里有一道相关的问题，而且以前已经解决——求直角三角形边长。你能利用它吗？**

答：我的图中有直角三角形吗？没有……

**问：为了有可能利用它，你是否应该引入某个辅助元素？**

答：让我引入一个直角三角形，使得 x 是它的斜边！

此时，引入辅助未知量 y（底面对角线）。y 是直角三角形的斜边（a、b 为直角边）。x 是另一个直角三角形的斜边（y、c 为直角边）。

```
        引入辅助线 y：
        y² = a² + b²        (底面直角三角形)
        x² = y² + c²        (空间直角三角形）
    ==> x² = a² + b² + c²
    ==> x = √(a² + b² + c²)
```

### 这个阶段的核心步骤回顾

1. 「看着未知量」→ 未知量是线段长度 → 联想到直角三角形
2. 「引入辅助元素」→ 画底面对角线 y → 出现两个直角三角形
3. 「利用已解决的问题」→ 两次应用勾股定理
4. 「消除辅助未知量」→ 代入消去 y

### 另一种路径：类比

也可以走类比路线：

**问：能不能想到一个更简单的类比问题？**

—— 平面几何中的类似问题：已知长方形的长和宽，求对角线。

然后在长方体中"嵌入"这个长方形，将空间问题化归为平面问题。

### 编程迁移

| 数学策略 | 编程策略 |
|----------|----------|
| 看着未知量 → 联想到直角三角形 | 看着目标输出 → 想到类似的现有功能 |
| 引入辅助线 y | 引入中间变量、辅助函数、wrapper |
| 两次应用勾股定理 | 复用一个已验证的工具函数两次 |
| 消除辅助未知量（代入） | 内联/化简中间结果 |
| 类比平面问题 | 参考另一个模块的类似实现 |
| 问：所有数据都用上了吗？ | 所有入参都用到了吗？所有需求都满足了吗？ |

---

## 阶段三：执行方案

### 逐步验证

1. y² = a² + b² — 这一步对吗？是的，由勾股定理，底面是长方形。
2. x² = y² + c² — 这一步对吗？需要确认 x、y、c 构成直角三角形。
   - **你能清楚地看出这一步是正确的吗？**（直觉）
   - **你能证明它是正确的吗？**（形式证明）（如果学生没有立体几何基础，这一步可以先跳过形式证明）
3. x² = a² + b² + c² — 代入即可。
4. x = √(a² + b² + c²) — 取正根。

### 编程迁移

| 数学执行 | 编程执行 |
|----------|----------|
| 每一步确认其正确性 | 每改一个函数就跑测试 |
| 直觉验证 + 形式证明 | 肉眼 review + 编译器/测试验证 |
| 大步验证、小步验证 | 先验证主流程，再验证边界和细节 |

---

## 阶段四：回顾

### 检验结果

- **所有数据都用上了吗？** — 是，公式中出现了 a、b、c。
- **问题关于 a、b、c 是对称的，你的公式对称吗？** — 是，交换 a、b、c 公式不变。
- **如果 c 减小到 0，长方体变成平面长方形。c=0 时代入公式得到正确结果吗？** — 是，得到长方形对角线公式 √(a² + b²)。
- **如果 a、b、c 同时放大 k 倍，对角线也放大 k 倍吗？** — 是，代入 ka、kb、kc 得到 kx。
- **单位一致吗？** — a、b、c 如果是英尺，x 也是英尺。

### 改进和泛化

- **能用不同的方式得出结果吗？** — 可以不引入 y，直接用长方体对角线的几何性质；也可以用向量法。
- **能把这个结果或方法用于别的什么问题吗？** — 可以求长方体中心到顶点的距离（x/2）。可以求空间中从一点到另一点的直线距离（三维距离公式）。可以推广到更高维度。

### 编程迁移

| 数学回顾 | 编程回顾 |
|----------|----------|
| 所有数据都用上了吗？ | 所有需求/约束都满足了吗？ |
| 检验对称性 | 边界值测试、负值测试、空值测试 |
| c=0 退化为平面问题 | 边界条件退化为已知的简单情况 |
| 比例一致性检验 | API 幂等性、一致性验证 |
| 能用不同方法得到相同结果吗？ | 有更简洁的实现吗？能重构吗？ |
| 方法能用于其他问题吗？ | 这个模式/解法能泛化到其他模块吗？ |
